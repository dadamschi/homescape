# Pre-Handoff Quality Checklist

Run this before presenting any post. If an item fails, fix it — don't ship around it.

## Substance

- [ ] Meets the word floor (service/guide 700–1,200; project/seasonal 600–1,000; permit-data 500–800).
- [ ] Covers ONE distinct topic; confirmed it's not a rehash of an existing post.
- [ ] At least one concrete number, list, OR table — not all adjectives.
- [ ] Local specificity present (Chicago neighborhood, permit reality, or seasonality).

## Structure

- [ ] H1 = specific title, no doubled brand suffix.
- [ ] 40–60 word lead answer sits directly under the H1.
- [ ] 3–6 H2 sections; at least one phrased as a natural question.
- [ ] FAQ block with 3–5 Q&As, 40–60 word answers.
- [ ] Exactly ONE soft CTA at the end.

## Front-matter / import readiness

- [ ] `_type` is `blogPost`.
- [ ] `publishedAt` is BLANK (drip-publish plan assigns it).
- [ ] `seo.metaTitle` has exactly one ` | Homescape Construction` suffix (max 60 chars).
- [ ] `seo.metaDescription` ≤ 160 chars and includes location + primary phrase.
- [ ] `mainImage` is a real, UNIQUE image (not the shared hero).
- [ ] `faq` array uses `question` and `answer` fields (not `q` and `a`).
- [ ] `categories` uses valid options: Remodeling, Permits, Seasonal, Projects, Guides, Chicago Trends, Home Improvement.

## Honesty / E-E-A-T

- [ ] No fabricated permit numbers, prices, addresses, names, quotes, stats, or credentials.
- [ ] Any figure not supplied is written as a labeled range.
- [ ] History/claims consistent with the agreed true founding story (no "1995 vs 2012" conflict).
- [ ] Attributed to a real person where possible.

## Voice

- [ ] No banned slop phrases (see voice-and-eeat.md).
- [ ] Varied sentence rhythm; plain, concrete, contractor-to-neighbor tone.
- [ ] Jargon defined where used.
